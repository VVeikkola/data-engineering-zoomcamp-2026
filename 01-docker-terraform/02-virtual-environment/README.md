# 02 – Virtual Environments and Data Pipelines

## Objective

Understand data pipeline fundamentals, Python dependency management, and efficient data storage formats.

## What I Learned

- Data pipelines and ETL fundamentals
- Command-line arguments using `sys.argv`
- Python virtual environments
- Dependency management with uv
- Dependency version locking
- Pandas DataFrames
- Apache Parquet and columnar storage
- Differences between CSV and Parquet
- Python exception types

## Practical Exercises

- Building a simple parameterized Python data pipeline
- Creating and processing pandas DataFrames
- Exporting data to Parquet files
- Running Python scripts using uv
- Managing project dependencies
- Excluding generated data files from version control

## Key Takeaway

Parameterized data pipelines and reproducible Python environments provide a foundation for reliable data processing. Columnar formats such as Parquet can improve storage efficiency and analytical query performance.
